# gates/ —— 门禁（把承诺转成非零退出命令）

**首版（L2 及以下）此目录为空。**

将来放什么：
- 把"必须 / 禁止"的承诺固化成**非零退出命令**，每门配一个**负样本 spec**（构造非法样例证明门会拒绝）。
- 典型：格式门（决策格式契约）、链接门、分类门（lifecycle×class 封闭集合）。
- 分层：本地钩子（秒级）抓局部，CI（持续集成，分钟级）抓全量。

为什么现在空：首版刻意止步 L2 的「承诺可验」——L2 的判据是"有非零退出门禁 + 负样本"，
它需要实际脚本；本框架首版交付的是骨架与判据，不预置具体的**门禁脚本**（不同技术栈、不同托管
平台的门禁实现各不相同，见 methodology.md §4「三层门禁」）。（注：这里说的"脚本"仅指实例化后
才有的门禁脚本；框架 CLI 本身 `ponygo` 是已交付的 shell 脚本，与此不同。）

升到 L2 时，往这里放你的第一个门，并同步把 `meta.yaml` 的 `level` 改为 `2`。

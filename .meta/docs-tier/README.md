# docs-tier/ —— 文档分层（按 tier 分类法给每个事实安一个家）

**首版（L3 及以下）此目录为空。**

将来放什么：
- tier 分类法：把"事实"按职责分到固定若干 tier（如：常载命约 / 决策记录 / 类型参考 /
  how-to / 事故复盘），每一 tier 的「该承载什么 / 不该承载什么」写死。
- slop checklist（审计清单）：同一条规则是否重复出现在多个家、是否叙述历史、是否强调通胀。
- 词数预算：standing-doc 设上限，超出即拆分或降级。

为什么现在空：文档分层是 L3 的产物，依赖"文档已经多到需要分层"这一事实。

升到 L3 时，往这里放你的 tier 定义与 slop checklist。

# Agent Note: 技能卫生纪律与简化勘探证据链

Status: implemented

## Problem

技能目录生长后出现两类失真：一是模型可见的工具定义改动散在正文，
触发条件藏进深层、同一事实在定义与提示节互抄，上下文越改越大；
二是删除类提案只凭符号零命中立论，动态消费者与扩展点未被举证，
历史成功案例被当成删除清单复用。

## Decision

技能契约下已新增两条纪律（skills README 纪律 4/5，节首写死追溯句：
"本节仅约束本提交之后新增/改写，既有三技能豁免；改写指工具定义/提示节/步骤/
样例/验证语义任一变更，纯 typo/格式除外，边界靠 review"）：

- **工具定义卫生（纪律 4）**：最小上下文优先；延迟加载资源全部可检索；
 关键约束前置到动作前；输出有界，给标识或路径而非全文倾倒；
 每事实只说一次；有条件者记录（模型名 + 提示版本 + 输入 token 数），
 无条件者诚实标注未测（token 测量为有条件记录，非门禁）。
- **简化勘探证据链（纪律 5）**：删除或收窄类提案给出证据链四件套
 （owner、producer/consumer 路径、消失/保留清单、最强反方）；
 符号零命中不等于可删；历史案例只作提问清单；计数不选优。

方法论侧追加同源原则句（§3.3 模式 11/12、§7.1 证据链四件套 + 计数不选优），
细则只留技能契约一家，methodology 只留原则句 + 链入。

## Alternatives considered

- **全量返工既有技能**：否决。无真实消费者驱动，违反三次法则豁免理由。
- **只收卫生、不收证据链**：否决。两类失真同属技能生长期的对称问题，
 分开收会留半边。
- **写成 L2 硬门禁**：否决。两条均为语义判断，只能靠 review。

## Consequences

- `.agents/skills/README.md` 纪律 4/5 + 追溯句；`docs/methodology.md` §3.3 钉 11/12、
 §7.1 增补证据链四件套 + 计数不选优；
- `tests/run.sh` s32-S 断言纪律全称 + 追溯句 + methodology 新增句；
- 纪律被读成追溯返工的风险 → 节首追溯句对冲；
- 证据链被当成固定模板的风险 → 保留理由与提问清单属性靠 review 守住。

> 实证出处注：卫生纪律源自 deepseek-harness 的 `agent-experience` 技能
> （最小上下文 / 发现显式化 / 约束前置 / 有界输出 / 每事实一次）；
> 证据链源自其 process 类 2026-09-19 简化勘探决策
> （producer→outcome 全路径 / 失去能力清单 / 最强保留理由 / 计数不选优）；
> ponygo 侧只收通用纪律句，不收其 token 量测与试验计数。
